# Prompt 06 — Application Build

Design and build the minimum application that proves the selected intervention. First provide a spec before app development starts

Specs for app development:
- Consider output of ADRs.md, DDD to create a spec for application. 
- Take an agentic approach and decide what agents to be made
- Use data contract based on adrs between the agents
- use local database, if not available use lightweigths like equivalent of cosmos db 
- Data - use data from data folder and also use DDD document on data dependencies

Tech stack to use:
- Frontend : React with tailwind css
- Backend : fastapi, python, nosql db

Before coding, define:

- primary user;
- decision workflow;
- required evidence;
- derived outputs;
- uncertainty behavior;
- authorization boundaries;
- testable acceptance criteria.



Do not hard-code findings or priority records. Preserve provenance and contradictory evidence.
